A [make.fun](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty entry: one funny line, written by a program.

## The line

> My doctor told me to cut back on screen time, so now I watch my phone in the mirror and call it self-reflection.

## How it works

`main.py` writes that single line to `/output/entry.txt` (or to the directory named by `MAKEFUN_OUTPUT_DIR` when the harness sets it). The line is 112 characters, one line, plain UTF-8, inside the competition gate of 1 to 140 characters.

## Run it

```sh
python3 main.py
```

Then check the output:

```sh
cat /output/entry.txt
```
